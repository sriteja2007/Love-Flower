# 🌸 Love Flower Website

A romantic interactive gift website inspired by the Instagram viral floral gift animation.

## ✨ Features

- 🎁 **Surprise Gift Landing**: Tap the gift box to unlock the romantic experience.
- 🌹 **Cascading Rose Bloom**: Smooth floating flower petal shower animation with curtain split reveal.
- 🎵 **Romantic Background Music**: Plays automatically upon opening the gift.
- 💖 **Hero & Romantic Quote**: Elegant typography and illustrations.
- 🔒 **Interactive Passkey Padlock**: Heart padlock with pin keypad modal (Passkey: `1234`).
- 🌿 **Floral Loading Animation**: Wreath spinner with realistic petal transitions.
- 📸 **Polaroid Photo Gallery**: Tilting polaroid photo cards showcasing cherished memories.
- 💌 **Animated Love Letter**: Beautiful word-by-word reveal of a heartfelt message.
- 📱 **Mobile & Desktop Responsive**: Tailored for both phone screens and desktop browsers.

## 🔑 Default Passkey
The padlock passkey is set to `1511` by default (can be customized in `assets/app.js`).
